# Contact propgate

propgate is a small product. The fastest way to reach the people who write it
is a GitHub issue on
[github.com/joaopcm/propgate](https://github.com/joaopcm/propgate/issues).
Use that for bugs, diagnosis codes that look wrong, API questions, and
anything that would otherwise become a support ticket about DNS.

Email [hello@propgate.dev](mailto:hello@propgate.dev) for account or security
matters that should not be public. Say which API key prefix (`pg_live_…`) you
are using, the domain id if you have one, and the diagnosis codes you saw —
not the full key. We do not run a phone line.

If you are integrating and stuck, start from the
[developer portal](/developers): the public checker needs no key, the OpenAPI
spec is at `/openapi.json`, and the [quickstart](/quickstart) walks signup,
profile, register, and verify. Agents should read `/llms.txt` first.

This page exists so a human or an agent can verify that propgate is a real
project with a real place to write, not a parked domain. The same links are
in the footer of every docs page and in the Organization JSON-LD on the
homepage.
