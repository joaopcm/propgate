# Delete a domain

<EndpointHeader method="DELETE" path="/v1/domains/:id" />

Stops tracking the domain. Nothing about it is checked again — the sweeper
has no row left to pick up, its timeline entries and stored result are gone,
and its `externalId` is free for a future registration to reuse. There is no
undo; register it again to resume tracking, starting from `pending`.

No CLI command yet — removing a domain is API-only.
