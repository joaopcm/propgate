# Update a webhook endpoint

<EndpointHeader method="PATCH" path="/v1/webhooks/:id" />

Pauses an endpoint or changes which events it receives. The URL is not
editable — a different URL is a different endpoint, so
[create](/api/webhooks/create) one and [delete](/api/webhooks/delete) the old.

Disabling is the reversible option: the endpoint stops receiving events but
keeps its id, its secret, and its
[delivery history](/api/webhooks/deliveries). Send `disabled: false` to
resume.
