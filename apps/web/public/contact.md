# Contact propgate

The fastest way to reach the people who write propgate is GitHub. Open an issue at https://github.com/joaopcm/propgate/issues for a bug, a wrong diagnosis, a question about an API response, or a feature. The diagnosis taxonomy at https://docs.propgate.dev/taxonomy is the map of every code the API can return; if a finding looks wrong, name the code.

There is no sales form on this site and no chatbot. The public checker does not collect an email address. If you already have an API key, you minted it by proving control of a mailbox through POST /v1/signup — that address is how we would reach you about the account, and it is not a support inbox.

Developer resources, so you do not have to wait on a human:

- API reference: https://docs.propgate.dev/api
- Authentication: https://docs.propgate.dev/authentication
- OpenAPI spec: https://propgate.dev/openapi.json
- CLI: npx @propgate/cli — docs at https://docs.propgate.dev/cli
- Node SDK: npm install @propgate/sdk — docs at https://docs.propgate.dev/sdk
- Webhooks: https://docs.propgate.dev/webhooks
- Agent index: https://propgate.dev/llms.txt

The product is source-available at https://github.com/joaopcm/propgate. Pull requests and issues are the contact channel.
